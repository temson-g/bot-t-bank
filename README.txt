БОТ УЖЕ ГОТОВ - НУЖНЫ ТОЛЬКО 3 ШАГА
====================================

1. SETTOKEN.bat (два клика) - вставить ключ Т-Банка.
   Ключ: приложение Т-Банк - «Т-Инвестиции» - шестерёнка -
   «Торговый API» - «Сгенерировать токен».
   Вставляет ПРАВОЙ кнопкой мыши (вставить).
   Если ключ уже вставлен - пропускать этот шаг.

2. CHECK.bat (два клика) - проверка ключа.
   Ждём надпись «Ключ работает!».
   Если ошибка - скопируй ВЕСЬ текст окна и пришли в чат.

3. START.bat (два клика) - запуск бота.
   ОКНО НЕ ЗАКРЫВАТЬ - в нём живёт бот!
   Бот работает сам каждые 10 минут, даже когда ты занят.
   Дневник бота: файл bot.log (открывается Блокнотом).

ПОЧЕМУ БОТ НЕ ПОКУПАЕТ СРАЗУ
   Он покупает только когда тренд поворачивает вверх
   (быстрая средняя пересекает медленную снизу вверх).
   Пока РУСАЛ в покатке - бот сидит в деньгах и пишет
   строки в дневник. Это нормально, а не поломка.

VPN МОЖНО НЕ ОТКЛЮЧАТЬ
   Бот сам пробует две дорожки: через VPN и напрямую в банк -
   и использует ту, что работает. Ещё бот сам «одобряет»
   государственные сертификаты (те, что не узнаёт Chrome,
   но узнаёт Яндекс-браузер) - ему это не помеха.
   Если что-то не работает - двойной клик по NETCHECK.bat
   (окно останется открытым) и пришли результат в чат.

БУМАЖНЫЕ И РЕАЛЬНЫЕ ДЕНЬГИ
   По умолчанию бот торгует ВИРТУАЛЬНЫМИ деньгами (DRY_RUN=1).
   Дай ему отработать в этом режиме хотя бы несколько часов,
   посмотри дневник - и только потом: открой файл .env Блокнотом,
   замени DRY_RUN=1 на DRY_RUN=0, сохрани, запусти START.bat
   снова - с этого момента ордера реальные.

ОСТАНОВИТЬ БОТА
   Ctrl+C в окне бота (деньги останутся в банке).
   Или мгновенно: приложение Т-Банк - Т-Инвестиции -
   Торговый API - «Мои токены» - отозвать.

СМЕНИТЬ КЛЮЧ (если старый отозван или просто для чистоты)
   SETTOKEN.bat - вставить новый ключ.

КОМПЬЮТЕР
   Должен быть включён и в интернете. Выключи «сон»:
   Параметры - Система - Питание - «Экран и спящий режим» -
   «Никогда» (и на батарее, и от сети).

НЕСКОЛЬКО АКЦИЙ (как настроить)
   Бот умеет следить за НЕСКОЛЬКИМИ акциями сразу.
   Открой .env Блокнотом. Вместо строки TICKER=... вставь:
   TICKERS=RUAL,AFLT,T,SIBN
   И сделай BUY_LOTS=1 (по 1 лоту на каждый тикер: 250-600 руб).
   Это: RUAL=Русал, AFLT=Аэрофлот, T=Т-Технологии, SIBN=Газпромнефть.
   Бот следит за всеми сразу: сигнал на любой из них -> покупка/продажа.
   Всего бот потратит не больше ~1500 руб (по лоту на каждую).

ОБНОВЛЕНИЕ (если пришёл новый архив с починками)
   Папку НЕ удаляй: распакуй новый архив СВОЕРХ старую
   (Место назначения: C:\, при запросе на дубликаты -
   «Заменить файлы»). Файл .env с твоим ключом останется.
