# Торговый бот (ПК) — версия 2026-11-04a

## Что внутри архива
- `bot.py` — сам бот: каждые 10 минут смотрит цены и бегуны,
  покупает/продаёт, пишет всё в `bot.log`;
- `notify.py` — связь с банком (не менять);
- `local_ca.pem` — «бейдж» банка (не менять; если файла вдруг не
  окажется, бот сам восстановит его при первом запуске);
- `.env.example` — образец файла `.env` (нужен только на новом ПК).

## Обновление (бот уже установлен в C:\trading-bot-pc)
1. Распакуй архив В ПАПКУ C:\trading-bot-pc.
2. Windows спросит «Заменить файл?» — жми **«Да»** на `bot.py`,
   `notify.py`, `local_ca.pem`. Остальные файлы (`.env`, `START`,
   `bot.log`, `orders_state`, `python`) НЕ трогай.
3. В окне бота нажми **Ctrl+C**, дождись остановки, запусти **START**
   заново.
4. Проверь первую строку «БОТ ЗАПУЩЕН» в логе: там должно быть
   **«версия 2026-11-04a»** и **«быстрый выход 5% ниже MA20,
   покупка только выше MA20»**. Если стоит старая «2026-10-30a» —
   файл не заменился, повтори шаги 2–3.

## Правила (что бот делает)
1. **Покупка**: «быстрый бегун» MA20 выше «медленного» MA50 И
   цена выше бегуна MA20. Покупает 25% свободных денег,
   минимум 1 лот, если на него хватает.
2. **Продажа (обычная)**: MA20 опустился ниже MA50 — продаёт всё.
3. **Продажа (быстрый выход, НОВОЕ)**: цена ушла на 5% и более
   НИЖЕ бегуна MA20 — продаёт всё сразу, не дожидаясь
   пересечения (страховка от крутого падения). В логе строка
   с ⚡ «БЫСТРЫЙ ВЫХОД».
4. **Защита**: пока цена ниже бегуна MA20 — бот ничего не покупает
   (не ловит падающий нож; после быстрого выхода так же ждёт
   возврата цены выше бегуна).
5. Ордера — только по будням с 9:00 (дневная и вечерняя сессии).
   Вне сессии бот только наблюдает.

## Как остановить
- Ctrl+C в окне бота (или крестик на окне) — остановится сразу.
- Экстренно: отозвать токен в приложении Т-Банка
  (Т-Инвестиции → шестерёнка → «Торговый API») — банк перестаёт
  пускать бота.

## Журнал
- `bot.log` — дневник бота рядом с ним (Блокнотом): каждое решение,
  каждый ордер, все ошибки.
